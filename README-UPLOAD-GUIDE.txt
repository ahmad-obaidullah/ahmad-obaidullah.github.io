================================================================
STEP 0: One-time (5 minutes)
================================================================
1. Go to https://github.com and click "Sign up".
2. IMPORTANT: choose your username carefully, because it becomes
   your website address. Best choice: something like
   "ahmadobaidullah" or "ahmad-obaidullah".
   Your address will be:  https://<username>.github.io
3. Verify your email address.

================================================================
STEP 1: Create the site repository (2 minutes)
================================================================
1. While logged in, open:  https://github.com/new
2. Repository name:  <your-username>.github.io
   (EXACTLY like that; for example ahmadobaidullah.github.io)
3. Visibility: Public (required for the free site).
4. Tick "Add a README file".
5. Click "Create repository".

================================================================
STEP 2: Upload the site (3 minutes, no coding)
================================================================
1. On the repository page click:  "Add file" > "Upload files".
2. Open your folder:  Portfolio_Material - opCD_try2\portfolio_site
3. Select ALL items inside it (Ctrl+A) and DRAG them into the
   GitHub upload area (drag into the big drop zone, not the
   "choose your files" link). Modern Chrome/Edge preserves the
   subfolders (assets/, projects/, certifications/) when you drag.
4. Wait for the file list to finish processing, then click
   "Commit changes".
5. Wait 1-2 minutes, then open:  https://<your-username>.github.io
   Your portfolio is LIVE. Share that link everywhere
   (LinkedIn bio, resume, GitHub profile, X bio).

If dragging folders does not preserve structure in your browser:
  Alternative (still no coding): install GitHub Desktop
  (https://desktop.github.com), File > Clone repository > choose
  your <username>.github.io repo > copy-paste the CONTENTS of the
  portfolio_site folder into the cloned folder > in GitHub Desktop
  write "Portfolio live" as the summary > Commit > Push origin.
  (6 clicks, nothing to type except the summary.)

================================================================
STEP 2B: You ALREADY have a portfolio repo on GitHub
================================================================
Your live address comes from the repo name: <username>.github.io.
Do NOT create a new repo: updating the existing one keeps the
address and every link you have already shared.

Easiest exact-swap (GitHub Desktop, still no coding):
1. Install GitHub Desktop (https://desktop.github.com).
2. File > Clone repository > choose your <username>.github.io repo.
3. Open the cloned folder in Explorer and DELETE everything inside
   it (the old portfolio files).
4. Copy-paste the CONTENTS of the new portfolio_site folder in.
5. In GitHub Desktop: write "New portfolio" as the summary >
   Commit > Push origin. Done: same address, new site, in 1-2 min.

Web-UI alternative (no install):
1. Repo page > "Add file" > "Upload files" > drag ALL contents of
   portfolio_site (same-name files overwrite automatically).
2. Then delete leftover old files that are no longer in the new
   site: open each file > the "..." menu > Delete file > Commit.
   Tedious with many files; the Desktop method above is faster.
