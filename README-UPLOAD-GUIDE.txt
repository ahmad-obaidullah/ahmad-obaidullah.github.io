STEP 1 — Create the site repository (2 minutes)
================================================================
1. While logged in, open:  https://github.com/new
2. Repository name:  <your-username>.github.io
   (EXACTLY like that — e.g., ahmadobaidullah.github.io)
3. Visibility: Public (required for the free site).
4. Tick "Add a README file".
5. Click "Create repository".

================================================================
STEP 2 — Upload the site (3 minutes, no coding)
================================================================
1. On the repository page click:  "Add file" → "Upload files".
2. Open your folder:  Portfolio_Material - opCD_try2\portfolio_site
3. Select ALL items inside it (Ctrl+A) and DRAG them into the
   GitHub upload area (drag into the big drop zone, not the
   "choose your files" link). Modern Chrome/Edge preserves the
   subfolders (assets/, projects/, certifications/) when you drag.
4. Wait for the file list to finish processing, then click
   "Commit changes".
5. Wait 1-2 minutes, then open:  https://<your-username>.github.io
   Your portfolio is LIVE. Share that link everywhere
   (LinkedIn bio, résumé, GitHub profile, X bio).

If dragging folders does not preserve structure in your browser:
  Alternative (still no coding): install GitHub Desktop
  (https://desktop.github.com), File → Clone repository → choose
  your <username>.github.io repo → copy-paste the CONTENTS of the
  portfolio_site folder into the cloned folder → in GitHub Desktop
  write "Portfolio live" as the summary → Commit → Push origin.
  (6 clicks, nothing to type except the summary.)
